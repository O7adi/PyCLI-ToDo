# PyCLI-ToDo ✅

A simple and interactive command-line To-Do list application built with Python. This project allows users to easily manage their daily tasks directly from the terminal without any complex setup.

## ✨ Features
* *Add Tasks:* Quickly add new tasks to your list.
* *View Tasks:* Display all current tasks with their corresponding numbers.
* *Remove Tasks:* Delete specific tasks by typing their exact name.
* *Interactive Menu:* Runs in a continuous loop until you choose to exit.
